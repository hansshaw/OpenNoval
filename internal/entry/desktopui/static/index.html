MODEL CONNECTION

模型与连接设置

保存连接和模型库后，在这里选择默认模型。暂停后可切换；角色专属模型在“创作资料与 Agent”中设置。

API Key 仅保存在本机配置，页面不会回传完整 Key。测试连接会产生一次简短模型请求。

留空或填 0，保存后自动获取上游参数；上游未声明时采用内置参考或兼容回退。填写数字则作为此模型的独立覆盖值。

选择已保存模型可修改其参数；编辑后请先保存，再切换到其他模型。新模型会加入此连接的模型库，其他模型参数保持不变。

生图模型设置

只管理生图连接与默认模型，独立于其他能力。Key 仅保存在本机，保存不会调用模型。

OpenAI 兼容连接使用 /images/generations。自定义协议暂不执行生成；请确认服务商支持对应接口。

视频模型设置

只管理视频连接与默认模型，独立于其他能力。Key 仅保存在本机，保存不会调用模型。

OpenAI 兼容连接使用 /videos（异步生成）。自定义协议暂不执行生成；请确认服务商支持对应接口。

语音模型设置

只管理语音连接与默认模型，独立于其他能力。Key 仅保存在本机，保存不会调用模型。

OpenAI 兼容连接使用 /audio/speech。自定义协议暂不执行生成；请确认服务商支持对应接口。

# AI Novel Studio

面向长篇小说创作的桌面工作台。通过共创、规划审核和章节生成三个阶段组织创作，支持多项目并行、共享风格语料库、章节版本与人工编辑、配图管理和模型请求记录。

应用仅以桌面安装包提供。Electron 管理窗口、本地工作区和 Go 引擎进程；界面随安装包一起分发，无需另行部署服务。

## 安装与启动

从本项目的 [Releases](https://github.com/hansshaw/AInoval-web-ui/releases) 下载对应系统的桌面安装包：

| 系统 | 安装包 |
| --- | --- |
| Windows | `ainovel-desktop-<版本>-win-<架构>-setup.exe` |
| Linux | `.AppImage` 或 `.deb` |

Windows 安装向导可选择安装位置。Linux AppImage 增加执行权限后即可运行，Debian/Ubuntu 也可安装 `.deb`。首次打开后，在“模型与连接设置”中保存连接、API Key 和模型，再到“项目中心”新建作品。

Windows 后续升级时先退出应用，再运行新版安装包，使用原来的账户与安装范围；安装器会识别旧版本并沿用原目录，保留作品和本地设置，无需先卸载。Release 同时提供 `SHA256SUMS.txt` 校验值。

## 创作流程

1. **共创与原则确认**：与共创助手讨论题材、人物、矛盾、世界规则和结局等要素，检查并确认完整创作指令。
2. **规划与审核**：查看分卷和章节目录，提交修改意见或直接编辑规划。在尚未生成正文时可调整并覆盖原规划，第一阶段的记录和创作原则继续保留。
3. **章节生成与验收**：确认规划后设置批次并开始正文。后续目录调整需要重新审查和确认；已完成正文按用户明确指令重写。

“章节工作台”按卷组织目录，整体工作区、章节目录、正文和章节指令区分别滚动，长篇正文不会把指令推到页面末尾。顶部定位栏可直达目录、正文、编辑或章节指令；窄窗下指令区移到正文前方。切换章节时正文回到顶部，保留目录和工作区的滚动位置。

中栏可切换阅读与编辑；正文编辑框独立滚动，保存操作位于编辑区底部。可以直接编辑卷名、章名、章节规划和正文；保存规划后，后续生成读取修改后的内容。采用重写稿或手改正文后，先同步修订并更新章节事实，再继续生成。

已完成或已确认的章节支持批量重写。新稿默认保存为候选版本，用户可比较版本并逐章采用，也可在提交时勾选自动覆盖。原稿保留在章节版本记录中。

## 项目、风格与模型

- **项目中心**：新建、搜索、重命名、复制、归档和恢复项目。每个项目使用独立目录、状态与作品锁。
- **项目并发**：默认允许 3 个创作项目同时运行，项目名额与模型请求并发分别配置。切换项目不会停止原项目，暂停只作用于当前项目。
- **共享风格语料库**：上传 TXT/Markdown 并蒸馏为具名风格画像，各项目勾选需要引用的条目。风格分析可与正文创作同时进行。
- **模型与连接设置**：管理多个连接、模型参数、当前默认模型和角色专属模型。密钥保存在本机配置，不回传到界面或写入桌面索引数据库。
- **活动记录**：查看运行事件、模型请求状态和错误信息。流式输出保持开启，中断恢复以已保存章节与检查点为准。
- **版本与恢复**：为项目创建命名快照、查看差异并预览恢复；恢复前自动备份，项目副本拥有独立版本链。
- **导出**：通过系统“另存为”对话框导出 TXT、EPUB 或章节配图包。先暂停目标项目并等待任务结束，导出会在作品锁保护下读取一致快照；其他项目可继续创作。

## 界面外观

点击右上角的外观按钮，即可切换八种界面皮肤：

| 皮肤 | 视觉设计 |
| --- | --- |
| 原始静态（默认） | 保留熟悉的深色工作台，关闭动效 |
| 水墨 · 远山 | 宣纸色、青绿远山与朱砂印记 |
| 清爽 · 晨间 | 薄荷绿、明亮卡片与植物插画 |
| 暧昧 · 微醺 | 玫瑰暮色、柔和光环与紫色层次 |
| 原神风 · 星旅 | 天空、浮岛、星轨与鎏金装饰的原创幻想风格 |
| 星空 · 深空 | 漂移星群、星云光晕与偶尔掠过的流星 |
| 极光 · 夜幕 | 青绿、蓝紫光幕与夜空中的缓慢波动 |
| 流光 · 丝绸 | 香槟金与烟紫色交织的绸缎褶光 |

选择皮肤即时生效，不刷新页面或丢弃正在编辑的内容。外观和动效偏好保存在本地 SQLite，重启后自动恢复；可一键恢复原始静态界面。水墨、清爽、暧昧和原神风使用原创 SVG；星空、极光和丝绸流光由本地 Canvas 绘制，无需联网加载图片、字体或动画库。

首次启动保持原始静态界面。主动切换到星空、极光或丝绸流光时默认开启动效，可随时通过“动态效果”开关暂停；保存关闭后重启仍保持静止，再切换到另一款动态皮肤会重新开启。其他皮肤的边缘流光也由该开关控制。系统启用“减少动态效果”时自动静止，窗口隐藏时暂停绘制。

动画位于装饰背景，不拦截点击；正文、输入框、弹窗和提示保持不透明底色。皮肤只改变界面外观，与创作风格语料库无关。设计参考、关注度调研和性能策略见 [动态皮肤说明](docs/dynamic-themes.md)。

## 章节生图、视频与朗读

“章节媒体”可选择指定章节的已保存正式正文或草稿，调用生图、视频或语音模型。章节工作台提供“本章生图 / 本章视频 / 本章朗读”入口；只有规划、没有正文时不能生成。画面要求只作用于图片与视频，朗读使用正文，长章分段处理且不会静默截断。

“模型与连接设置”分为文本创作、生图、视频和语音四个独立面板，每类连接和默认模型独立管理。媒体生成支持 OpenAI 兼容的 Images、Videos 和 Audio Speech 接口；语音可配置音色。自定义协议目前仅保存配置。保存设置不会发送生成请求，点击生成才调用对应服务商。

生成的图片加入本章配图，音频与视频可在任务卡内播放、下载。视频生成的是依据章节关键场景制作的短片，当前请求时长为 4 秒。任务及产物随项目保存，切换章节后不会串用结果，重启后仍可查看已完成内容。生成期间正文发生变化时，结果不会自动关联到修改后的正文。

也可导入本机 PNG、JPEG、WebP 和 GIF 图片，调整说明、顺序以及章首/章尾位置，在章节工作台阅读正文时显示。配图随项目保存、复制和版本快照保留；章节配图包包含正文、规划和图片，音视频单独下载。

媒体扩展使用独立的自有实现，位于 `internal/mediaworkspace/`。界面资源与章节配图包格式集中在该目录；图片文件管理位于 `internal/chaptermedia/`，桌面接口负责项目租约与权限检查。章节配图包使用中性 JSON 与原始图片文件，不要求特定画布产品，可在后续替换渲染或生成技术时复用。

## 本地开发

需要 `go.mod` 指定版本或更新的 Go、Node.js 26 和 npm。安装后的桌面应用不要求用户另外安装这些开发工具。

在仓库根目录执行：

```sh
npm --prefix desktop ci
node desktop/node_modules/electron/install.js
npm start
```

`npm start` 会编译桌面专用 Go 进程并启动 Electron。独立构建该内部进程使用 `npm run build:sidecar`；它由桌面主进程管理，不提供独立创作入口。

```sh
go test ./...
go vet ./...
npm test
npm run smoke
npm run test:e2e
npm run dist
```

Linux 无图形会话时使用 `xvfb-run -a npm run smoke` 和 `xvfb-run -a npm run test:e2e`。安装包输出到 `desktop/dist/`，构建完成后可运行 `npm run smoke:packaged` 验证随包应用。完整环境、数据位置和打包说明见 [桌面开发文档](desktop/README.md)。

## 代码结构

| 目录 | 职责 |
| --- | --- |
| `desktop/` | Electron 主进程、窗口、系统对话框、索引数据库与打包 |
| `cmd/ainovel-desktop/` | 桌面专用 Go 进程入口 |
| `internal/entry/desktopui/` | 桌面界面、内部接口与项目操作 |
| `internal/host/`、`internal/engine/` | 创作生命周期、调度与断点恢复 |
| `internal/store/` | 正文、规划、角色和连续性事实 |
| `internal/projectjobs/` | 项目任务队列与并发额度 |
| `internal/mediaworkspace/` | 可替换的媒体界面与章节配图包格式 |
| `internal/chaptermedia/` | 章节图片校验、存储和元数据 |

## 数据与许可

作品保存在桌面用户数据目录内，正文和规划等文件是项目的事实来源，SQLite 保存界面索引和运行快照。已有项目目录和模型配置保持兼容；历史数据路径中的 `web-books` 名称仅为兼容保留，无需手动迁移。

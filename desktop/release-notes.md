# 开发变更记录（尚未发布）

当前更新仅提交并 push。安装包由 CI 构建为 Actions artifacts，不自动创建 Release。

## 小说阅读与手动创作

- 新增整本阅读器，支持本项目作品及 TXT、EPUB、PDF、DOCX、Markdown、HTML 导入。
- 支持目录、全文搜索、书签、阅读进度、字号、行距与独立阅读配色。
- PDF 可切换原页和提取文字；扫描 PDF 可读原页，当前不提供 OCR。
- 导入内容成为可编辑的手动项目，直接联通章节朗读、配图、视频与共享风格语料库。
- 无需配置模型即可手动建项目、创建空章、修改标题和正文；清空正文仍可从历史版本恢复。
- 导入发布、阅读进度、复制与项目快照遵守工作区锁，失败导入不会留下可见半成品。

## 界面与工作区

- 章节目录、正文、编辑框、指令及整体区域独立滚动，常驻定位栏可直达操作区。
- 新增星空、极光与丝绸流光动态皮肤，与原有皮肤一起可选。
- 动效在本机绘制，文字使用清晰底色；隐藏窗口、减少动态效果模式会暂停绘制。
- 默认保持原始静态外观，已保存的暂停偏好在重启后恢复。

## 安装、许可与维护

- Windows 安装器身份保持稳定，新版安装包可沿用原目录，保留用户数据。
- 项目整体许可改为 AGPL-3.0-only，必要第三方声明与许可随安装包提供。
- 应用内提供离线许可查看和本项目源码入口。
- README 按当前特色功能重写，移除旧项目品牌与过时入口。

桌面测试覆盖真实 Electron、六种文档格式、PDF 渲染、手动章节保存恢复、八套皮肤、媒体联动及重启持久化。付费模型接口使用本机模拟服务；Windows 安装升级由 Windows CI 验证。

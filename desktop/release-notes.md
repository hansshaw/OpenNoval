AI Novel Studio v0.1.2：章节独立滚动工作台与星空、极光、丝绸流光动态皮肤。

### 本次改进

- 章节工作台、目录、正文和指令区分别滚动。桌面宽窗口下，指令与版本放在正文旁边；窄窗口下指令前移，可通过常驻定位栏直接到达，无需先滚完整章正文。
- 阅读与编辑分开切换，保留未保存草稿；编辑正文使用独立滚动条。切章只重置正文位置，目录和工作区位置不受影响。
- 章节页的风格库引用默认折叠，可随时展开，减少进入工作台时的滚动距离。
- 新增星空 · 深空、极光 · 夜幕、流光 · 丝绸三种动态皮肤，与原有五种皮肤一起可选。切换到新动态皮肤即可看到持续变化的背景，可手动暂停；暂停偏好在重启后保留。首次安装仍默认原始静态界面。
- 动态场景为随包提供的原创 Canvas 绘制，无需联网下载资源。背景不接收点击，正文、输入框和弹窗保留实色底板。窗口隐藏、系统减少动态效果或高对比度模式下停止绘制；限制帧率与像素数量，慢设备自动降低绘制负荷。

### Windows 安装与升级

下载 `ainovel-desktop-0.1.2-win-x64-setup.exe`。首次安装可选择目录；已安装旧版时，先退出应用，使用同一 Windows 账户和安装范围运行新版安装包，即可默认沿用原目录更新。无需先卸载，作品、数据库与设置保留。

这是下载安装包后运行的就地升级，尚未启用应用内自动下载更新。Windows 安装包暂未配置代码签名。

### 验证范围

桌面验收覆盖八套皮肤在 100%/125%/150% 缩放下的页面与弹窗、主要文字对比度、背景实际像素变化及暂停、隐藏与恢复、动态皮肤暂停偏好跨进程保存，以及长章节独立滚动与指令定位。章节媒体生成继续使用本地模拟服务和可实际解码的图片、音视频进行回归，不消耗付费 API。

发布流水线在 Windows 和 Linux 上运行真实 Electron 与安装后验收。Windows 同时验证自定义目录升级和上一公开正式版安装包的升级、数据保留。Linux 提供 `.AppImage` 和 `.deb`；`SHA256SUMS.txt` 用于核对安装包，`.blockmap` 无需手动安装。

视觉调研参考高关注度项目 [React Bits](https://github.com/DavidHDev/react-bits)、[tsParticles](https://github.com/tsparticles/tsparticles) 和 [Vanta](https://github.com/tengbao/vanta)。本次使用原创轻量实现，无需引入这些项目的运行依赖。

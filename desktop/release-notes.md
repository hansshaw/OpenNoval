### Windows 安装与后续升级

下载名称以 `win-x64-setup.exe` 结尾的安装包，适用于 Windows x64。首次安装可选择目录。

升级时先退出应用，直接运行新版本安装包，使用与旧版本相同的 Windows 账户和安装范围。安装器会识别旧版本并默认沿用原安装目录，替换程序文件；无需先卸载。作品、本地数据库与偏好保留在用户数据目录中。

这里提供的是下载安装包后运行的就地升级；应用内自动下载更新尚未启用。安装包暂未配置 Windows 代码签名。

### 验证与其他下载

Windows 安装器经过自定义目录安装旧版本、运行新安装包且不指定目录、检查原目录和数据保留、启动安装后应用的验收；同时运行桌面单元测试、前后台创作流程、真实 Electron 与重启持久化测试。

Linux 用户可下载 `.AppImage` 或 `.deb`。`SHA256SUMS.txt` 提供安装包校验值；`.blockmap` 为构建辅助文件，无需手动安装。

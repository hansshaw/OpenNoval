AI Novel Studio v0.1.1：独立媒体模型配置、章节生图/视频/朗读与 Windows 换肤显示修复。

### 本次修复与新增

- 模型设置拆为文本创作、生图、视频、语音四个独立面板，分别保存连接和默认模型，切换面板保留正在编辑的内容。
- 指定章节可选择已保存正式正文或草稿，生成配图、4 秒场景视频或整章朗读。章节工作台提供三个直达入口，规划和未保存内容不会作为正文提交。
- 支持 OpenAI 兼容的 Images、Videos 和 Audio Speech 接口。长章朗读分段处理，不静默截断；任务和产物随项目保存，支持播放、下载与重启后查看。切项目后结果仍保存回原章节，正文变化时不自动关联旧结果。
- 修复换肤和 Windows 高缩放下导航与顶部栏重叠、工具按钮溢出、页面切换沿用旧滚动位置的问题；内容不再依赖入场动画，窗口隐藏时只暂停装饰流光，避免页面停在透明帧。
- 修复媒体另存为仅支持文档/ZIP的问题，支持图片、MP3、MP4。

### Windows 安装与升级

下载 `ainovel-desktop-0.1.1-win-x64-setup.exe`。首次安装可选择目录；已安装旧版时，先退出应用，使用同一 Windows 账户和安装范围运行新版安装包，即可默认沿用原目录更新。无需先卸载，作品、数据库与设置保留。

这是下载安装包后运行的就地升级，尚未启用应用内自动下载更新。Windows 安装包暂未配置代码签名。

### 验证和接口范围

执行 Go 测试与竞态检查、桌面单元测试、真实 Electron 章节媒体与重启验收，并覆盖五套皮肤在 100%/125%/150% 缩放下的页面与弹窗。媒体生成验收使用本地模拟服务与可实际解码的图片、音视频素材，不消耗付费 API；真实服务需支持上述协议、所选模型与权限，自定义协议目前仅保存配置。

Windows 流水线验证自定义目录原位升级和数据保留，并在存在更早正式版时用公开发行的旧安装包再验证一次。Linux 同时提供 `.AppImage` 和 `.deb`。`SHA256SUMS.txt` 用于核对安装包，`.blockmap` 无需手动安装。

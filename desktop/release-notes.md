# AI Novel Studio v0.1.3

本次更新改善项目恢复、设定审核和整本阅读，并包含上一轮共创上下文与模型配置修复。

## 工作区与阅读体验

- 重新打开应用时恢复上次关闭前选中的项目；切换后立即退出也会保存最后选择。
- 首次启动直接进入空项目中心，自行创建或导入作品；取消强制保留的初始默认项目，旧版默认作品也可按归档、删除流程移除。
- 上次项目已删除、归档或无法打开时返回项目中心，删除最后一个项目后也可继续创建或导入。
- 规则审核、人物档案、世界规则、章节评审、事实记录与风格画像改为中文字段、分组卡片和列表，长内容可展开阅读。
- 整本阅读新增全屏按钮，支持文字与 PDF 原页；可按 Esc 或点击按钮退出，保留当前章节与阅读位置。

## 共创与模型配置

- 修复共创固定 2,048 token 输出预算导致多轮对话草稿截断的问题。
- 按模型能力分配输入与输出预算，去除重复草稿，长对话按需生成摘要检查点并保留完整原始历史。
- 截断回复最多恢复一次；失败不覆盖有效草稿，追加新要求后需要重新确认。
- 已配置模型可选择编辑；生图、视频、语音支持读取上游模型列表。
- 未填写 token 限制时优先采用上游明确声明的参数，手动覆盖与自动缓存分离；上游未公开限制时显示实际回退来源。

## 安装与升级

- Windows：下载 `ainovel-desktop-0.1.3-win-x64-setup.exe`。退出旧版后运行安装器，使用原账户与安装范围，可沿用原安装目录并保留用户数据，无需先卸载。
- Linux：提供 AppImage 和 Debian 安装包。
- `SHA256SUMS.txt` 提供安装包校验值。

已执行 Go 测试、静态检查、桌面单元测试与真实 Electron 回归；发布前通过 Windows/Linux CI、安装包启动检查和 Windows 原目录升级验证。模型接口验证使用本机模拟服务。
